## Содержание

1. Парная линейная регрессия по `x1` и `x2` листа `var6` из `regression.xlsx`: статистики, корреляции, коэффициенты, четыре метрики, прогнозы и графики ошибок.
2. Полиномиальная регрессия по `x2`: степени 1, 2, 3, 6 и 12, пятиблочная кросс-валидация только на train, R² и MAE для train/test, выбор степени 3.
3. Прогнозирование `salary`: проверка данных, обработка выбросов, матрица диаграмм рассеяния, стандартизация и one-hot-кодирование внутри Pipeline, линейная регрессия, kNN и дерево решений.

## Запуск

Данные `regression.xlsx` и `salary.csv` должны находиться в рабочей папке ноутбука. При запуске в Colab загрузите оба файла из этого репозитория через панель «Файлы» и выполните «Среда выполнения → Выполнить всё».

Для локального запуска установите зависимости из `requirements.txt`, откройте `lr3.ipynb` в Jupyter или VS Code и выполните все ячейки. Графики и полные таблицы прогнозов сохраняются в `results/`.
